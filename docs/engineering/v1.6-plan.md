# V1.6 实施设计与计划

基线 v1.5.0 / 9be3671ae5b159804dce163ca4fba1797c0b6b95。用户授权自主推进，不逐节等待教学验收。

设计：SQLite 会话存储；随机不可枚举 ID；完整 query/answer 对；乐观 revision 校验防止并发丢失更新。DELETE 清空内容并递增 revision；模型失败和领域失败不写成功历史。旧 /chat 无 session 参数的路径保持原调用；有 session 使用独立 service 构建历史并调用原 Agent。Workflow 只在模型决策/生成前插入有界历史，保持六节点和 trace。

上下文：默认最近10轮、12000字符（历史预算，不是 token；当前 query 单独保留）。数据库也裁剪，非无限存储；损坏内容安全报错或过滤无效轮次，绝不接受历史 system 角色。配置通过 KP_SESSION_MAX_TURNS/KP_SESSION_MAX_CHARS。

恢复：仅只读 search_knowledge_base 对明确连接/超时故障重试，默认最多2次、配置最多3次。calculator 参数/除零不重试，未知工具不自动重试。独立 diagnostics 记录 stage/attempt/status/category/retryable；旧 trace 字符串顺序保持。模型错误最终继续旧502/503/504映射。非模型工具故障保持领域 failed。

取舍：全局列表不能持久化且易污染；JSON 文件并发写易损坏；标准库 SQLite 最符合本机单实例需求。不做向量记忆、自动摘要或分布式会话。无认证，会话 ID 是 bearer capability，只适用于受控本机，不能公开宣称多租户安全。
