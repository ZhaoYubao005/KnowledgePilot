# KnowledgePilot V1.4 Release Readiness（候选，未发布）

2026-10-27，Asia/Singapore。正式封版保持 V1.3.0。V1.4 当前处于独立开发分支的人工审查准备阶段。

## 候选版本内容

- 必要环境变量统一；本地旧默认兼容，数据路径可配置；.env.example 不含真实密钥。
- 最小 Docker/Compose 单 API 容器，宿主 Ollama，Chroma 与原文一起持久化，UID 10001。
- Linux 路径与权限预检、安全启停、独立数据的可重复持久化验收器。
- 安全 JSON 日志、请求 ID、模型连接/读取期限、合理 HTTP 错误及脱敏异常上下文。
- 原 API、Service、Agent、Embedding、Chroma 的实际 HTTP 进程集成测试与结构化证据。

六条 API、默认 Dense、Agent 顺序执行与 Trace 保留；不增加产品功能、算法或框架，不修改冻结评测集。

## 当前发布判断

**GO：交付代码审查和本地工程验收。** 本轮 479 passed、1 skipped；实际本地 HTTP 29 请求/23 检查通过；真实 Ollama 聊天/Embedding/文档检索最小检查通过。模拟上游驱动的工具循环不等于真实模型自主工具选择。

**NO-GO：当前正式发布。** 需要人工审查确认且不能隐藏以下差距：

1. 当前候选 Docker Engine 不可达，容器重验 BLOCKED；历史 Step 1 的 9/9 不是当前候选镜像证明。确认发布范围前，补当前候选构建及 health/Ollama/UID/持久化验证，或由审查者明确接受范围受限的发布决定。
2. 原生 Linux 已按既定决策转为技术债，不阻塞本地工程主线；不得声称 Linux 已验收。
3. 文档更新先删索引再入库，失败时原文字节恢复不代表索引恢复。单独接受该债务；要求无损更新的生产用途当前不适合。
4. 完整备份恢复、跨平台 metadata 迁移、认证、公网部署、长期负载/多实例写入没有验收，不包含在当前能力承诺中。

## 人工发布前检查

审阅 Step 5 集成报告和原始证据，确认风险接受范围；评审独立分支到 main 的差异，不丢前序提交或用户工作。当前包元数据仍 1.3.0、OpenAPI version 仍 1.1.0，这是保留的正式/接口历史标识，本轮没有为了版本号修改生产源码。正式发布时需明确包版本、接口版本与发布版本的策略，再进行必要调整并验证。

Compose 沿用开发镜像名 knowledgepilot:v1.4-step1；它不表示正式版本身份。发布时记录候选 Commit、完整构建来源、image ID/digest 和部署证据。基础镜像与传递依赖完整锁定为可复现构建后续债务，不把仅 pin 直接依赖称为完全可复现。

合并 main、创建 v1.4.0 Tag、宣布正式封版必须另获人工确认；Step 5 提交/推送不包含这些操作。
