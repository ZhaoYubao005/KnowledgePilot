# V1.5 Workflow implementation plan

Goal: independent, bounded LangGraph execution without changing the Agent Loop.
Baseline: b5c760d425741d18d11d91377bcb74af46669246; user authorizes autonomous design, implementation, tests, commits and branch push.

Architecture: START -> initialize -> decide -> conditional direct/generate, retrieve, or tool -> generate -> finish -> END. Errors route to finish. Model decision uses strict discriminated Pydantic schemas; no keyword intent guessing. At most two chat model calls and one tool call. Explicit request route overrides allow reproducible Python/API use; auto uses structured Ollama output. Unknown route/tool/arguments fail closed. No retry and no graph cycle.

- [ ] Baseline: run existing pytest using Python 3.11 and isolated test directories.
- [ ] State/routing tests: create tests/test_workflow.py; run pytest and observe missing implementation; cover branches, ordering, errors, empty evidence, repeated invocation isolation, strict schemas.
- [ ] Core: add workflow/schemas.py, workflow/graph.py, workflow/model.py. Lazy production tool import; reuse transport and registry. Run focused tests.
- [ ] API: add api/workflow.py router and include it in app.py; keep six existing endpoints unchanged. Test request/response validation and classified errors.
- [ ] Acceptance: add scripts/verify_v15_workflow.py with isolated subprocess data, actual HTTP, actual registry/calculator and Chroma; simulated upstream provenance explicit. Optional real Ollama mode uses the same request paths.
- [ ] Regression: full pytest; pip check; baseline diff for old Agent/RAG/evaluation. Record exact results and limitations.
- [ ] Handoff: source signatures, state ownership, node routes, runnable examples, debug exercises, evidence and release readiness. Commit allowlist; record code SHA in follow-up documentation commit; push only the development branch.

Choice: explicit request route plus automatic schema-constrained model route provides usable deterministic entry and natural language routing. A regex router is too narrow; wrapping the old Agent in one node does not meet the task. Retrieval returns no_results without asking a model to invent evidence. Model exceptions use existing HTTP mappings; domain workflow failures return an explicit failed status and safe error code.
