Memory 让系统在后续交互中继续使用已有信息。短期上下文通常由当前请求的 messages 承载，包括系统提示、用户问题、工具调用和工具结果。模型据此理解当前任务并继续判断；其有效范围由传入的消息及本次运行过程决定。一轮请求中反复使用这些消息，可以支持多轮 Agent Decision。

长期 Memory 关注跨请求或跨会话的信息保留，例如用户偏好、已确认的事实和持续任务的进展。保存内容在后续交互中被重新读取和使用，才形成长期记忆能力。聊天记录、数据库或向量存储可以作为载体，系统还需要规定保存、读取和更新方式。用于检索参考文档的知识库，承担的是资料检索职责。

当前 KnowledgePilot V1.1.0 的 /chat 为每个请求重新建立 system 与 user 消息。Agent 在运行中追加工具调用和 Observation，形成单次上下文；trace 记录工具执行事实。当前实现没有把用户历史、偏好或会话状态保存为长期 Memory，也没有在下一次请求中自动恢复这些内容。现有边界是 stateless 请求与本次运行上下文。
